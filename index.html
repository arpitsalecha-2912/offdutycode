Save changes to GitHub

✅ Connected. Switch changes save straight to GitHub.
  1. Open GitHub → new fine-grained token.
  2. Repository access: tap Only select repositories, then pick offdutycode. (Permissions stay hidden until you do this.)
  3. Under Permissions, tap + Add permissions → Repository (or expand Repository permissions), find Contents and set it to Read and write.
  4. Tap Generate token, copy the github_pat_… code and paste it here.
  5. Can't see these options on your phone? Switch the browser to desktop site.

The key is kept only in this browser. Only connect on your own phone or computer.
