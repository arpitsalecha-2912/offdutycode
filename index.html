Save changes to GitHub

Guest visibility is stored in pages/settings.json in your repo, so every visitor sees the same thing. To let this page update that file, connect a GitHub key once on this device.

✅ Connected. Ticking a checkbox saves straight to GitHub.
  1. Open GitHub → new fine-grained token.
  2. Repository access: Only select repositories → offdutycode.
  3. Permissions → Repository → Contents: Read and write.
  4. Generate, copy and paste it here.

The key is kept only in this browser. Anyone using this device could use it, so only connect on your own phone or computer.
